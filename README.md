# From Complexity to Clarity: Advancing Disease Diagnosis with Explainable Machine Learning

Developed a medical image analysis system to assist in diagnosing respiratory diseases such as Pneumonia, COVID-19, and Asthma using chest X-ray images. The system uses advanced signal processing techniques, including Gaussian Wavelet Transform **(CWT-Guass)** and Short-Time Fourier Transform **(STFT)**, to extract meaningful features from image scalograms. A novel approach based on Smith Normal Form **(SNF)** was introduced, where a 32×32 image is divided into overlapping 5×5 sections to capture structural patterns. Additionally, a modified **LeNet-5** deep learning model was combined with a multi-layer perceptron (MLP) consisting of three layers (1054, 512, and 256 neurons). This architecture includes ReLU activation, batch normalization, and dropout to improve accuracy and prevent overfitting.
